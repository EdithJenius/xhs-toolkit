# XHS Toolkit · 小红书内容工具箱

5 个工具，覆盖素材搜集、图文制作、账号分析与发布。按需要挑选，组成自己的内容工作流。

### 01 · [Agent-Reach](vendor/Agent-Reach/README.md)｜找选题、读素材

- **功能：** 搜索和读取多平台内容，收集热点、选题与竞品素材。
- **适合：** 内容运营、电商研究、资料整理。
- **简介：** 内容工作流的信息采集入口，小红书渠道需单独配置。

### 02 · [图文分镜技能](vendor/baoyu-xhs-images/SKILL.md)｜文章变图文

- **功能：** 分析文章、规划分镜，制作多张小红书图片卡片。
- **适合：** 知识分享、商品介绍、教程制作。
- **简介：** 将长内容拆成易读的图片，出图需要宿主提供图片生成能力。

### 03 · [社交卡片技能](vendor/guizang-social-card-skill/README.md)｜把内容排好看

- **功能：** 制作杂志风、瑞士风卡片及公众号横版、方形封面。
- **适合：** 产品测评、品牌内容、信息密集型图文。
- **简介：** 用 HTML/CSS 排版并渲染为 PNG，方便调整文字和布局。

### 04 · [小红书 MCP](vendor/xiaohongshu-mcp/README.md)｜连接账号与发布

- **功能：** 账号登录、笔记搜索与读取、图文和视频发布。
- **适合：** 需要将小红书操作接入 Agent 的使用者。
- **简介：** 以独立本地服务运行，使用前需本人完成账号登录。

### 05 · [小红书运营技能](vendor/xiaohongshu-ops-skill/README.md)｜从定位到复盘

- **功能：** 账号定位、选题研究、内容生产、发布执行和复盘。
- **适合：** 持续运营账号的个人或团队。
- **简介：** 提供可复用的运营流程，当前浏览器操作依赖 OpenClaw。

---

建议流程：**收集素材 → 写稿 → 出图 → 检查 → 发布 → 复盘**。

各组件独立运行，依赖与账号需按需配置。
